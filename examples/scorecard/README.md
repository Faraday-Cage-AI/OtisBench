# Illustrative model scorecard

These made-up values demonstrate a scorecard layout. They are not evaluation results or a model ranking. The six display names match the Faraday Industrial Benchmark comparison; its results are not transferred to OtisBench.

All example values are deliberately equal. `illustrative-scores.json` uses `measured: false` and `example_value` so this fixture remains separate from run artifacts. Actual results require model-generated actions and checked campaign artifacts.
